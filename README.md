# xiaozhi-watch v2.0

Кастомная прошивка для умных часов на базе **Waveshare ESP32-S3-Touch-AMOLED-2.06**
с голосовым ассистентом XiaoZhi.

Основано на оригинальном проекте [xiaozhi-esp32](https://github.com/78/xiaozhi-esp32),
версия 2.0.4.

## Что нового в v2.0

### Энергосбережение
- Глубокий сон (deep sleep) с автоматическим уходом через **120 секунд** бездействия.
- Отключение Wi-Fi перед уходом в сон (`esp_wifi_stop()`).
- Пробуждение по кнопке **BOOT** (GPIO0, EXT1 wakeup).
- Экран гаснет через **10 секунд** бездействия.
- На зарядке экран гаснет (таймер энергосбережения активен всегда).

### Интерфейс
- Тёмная тема по умолчанию.
- Отображение дня недели под датой на главном экране.
- Отображение уровня батареи на главном экране.

## Совместимость
- Плата: **Waveshare ESP32-S3-Touch-AMOLED-2.06**
- ESP-IDF: **v5.5**
- Версия XiaoZhi: **2.0.4**
