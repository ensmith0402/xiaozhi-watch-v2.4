# xiaozhi-watch v2.4

Кастомная прошивка для умных часов на базе **Waveshare ESP32-S3-Touch-AMOLED-2.06**
с голосовым ассистентом XiaoZhi.

Основано на оригинальном проекте [xiaozhi-esp32](https://github.com/78/xiaozhi-esp32),
версия 2.0.4.

## Что нового в v2.4

### 🖥️ Четыре экрана (свайп)
- **Экран часов** — время, дата, день недели, уровень батареи.
- **Экран ассистента** (свайп влево) — статус (слушаю / думаю / говорю), текст общения.
- **Экран управления** (свайп влево ещё раз) — иконки ☀ (яркость) и 🔊 (громкость)
  с интерактивными слайдерами.
- **Экран календаря** (свайп вправо с часов) — текущий месяц, дни недели (Пн–Вс),
  числа месяца с подсветкой текущего дня, стрелки для переключения месяцев.

### ⚡ Энергосбережение
- **Глубокий сон (deep sleep)** с автоматическим уходом через **120 секунд** бездействия.
- **Отключение Wi-Fi** перед уходом в сон (`esp_wifi_stop()`).
- **Пробуждение по кнопке BOOT** (GPIO0, EXT1 wakeup).
- Экран гаснет через **10 секунд** бездействия.
- **Опрос батареи раз в 30 секунд** вместо каждой секунды.
- **Снижение частоты CPU до 80 МГц** в sleep mode.
- **Light-sleep** включён через `esp_pm_configure()`.

### 📊 Результаты теста
- **4% за 8 часов** в глубоком сне (при 400 мАч) — средний ток ~2 мА.
- Прогноз автономности: **до 8 дней** в режиме ожидания.

## 🛠️ Сборка

```bash
. ~/esp/esp-idf-v5.5/export.sh
cd ~/esp/xiaozhi-watch-v2.0
idf.py build

 Управление
Действие	Результат
Свайп влево с часов	Экран ассистента
Свайп влево с ассистента	Экран управления
Свайп вправо с управления	Экран ассистента
Свайп вправо с ассистента	Экран часов
Слайдер ☀	Яркость экрана (0–100)
Слайдер 🔊	Громкость звука (0–100)
🔋 Проверка энергосбережения
Отключите часы от USB.

Оставьте без действий на 10 секунд — экран погаснет.

Подождите ещё 2 минуты — часы уйдут в глубокий сон, Wi-Fi отключится.

Нажмите BOOT — часы проснутся и перезагрузятся.
